# Contributing

Thanks for considering a contribution. Before coding, open an Issue describing a reproducible problem or a small feature and why it helps real editors.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and standard-library modules for FrameLedger.
3. Run `python3 -m unittest discover -s tests -v`.
4. Include tests when changing validation or exports.
5. Open a pull request explaining behavior changes and any remaining limitations.

Please do not add fake usage metrics, spam pull requests, upload copyrighted media without rights, or include personal data in example assets.

All contributions are subject to the MIT License. Maintainers may not accept every feature request.
